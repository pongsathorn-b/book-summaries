# Memory Craft — Lynne Kelly

> "Memory is craft, not talent."

## Overview

[[30 Knowledge/Concepts/Lynne-Kelly.md|Lynne Kelly]] investigated how ancient cultures and medieval scholars had extraordinary memories before printing. She discovered that the "[[Art of Memory|Art of Memory]]" was a deliberate craft — and argues it should return to education.

## The [[Ancient Memory Art|Ancient Memory Art]]

Before writing, trained orators could deliver flawless speeches lasting hours. This was [[Technique|Technique]], not [[Talent|Talent]]. The [[Art of Memory|Art of Memory]] (ars memorativa) was deliberately suppressed when printing arrived — [[Literacy as Power|Literacy as Power]].

## Key Techniques

### [[30 Knowledge/Concepts/memory-palace|Memory Palace]] Network

Instead of one [[30 Knowledge/Concepts/memory-palace|Memory Palace]], use a network of linked palaces. Expert [[Memory Athletes|Memory Athletes]] use hundreds. This allows remembering thousands of items in sequence.

### [[Songline Method|Songline Method]]

[[Indigenous Australians|Indigenous Australians]] used epic songs that were [[Geographical Navigation Systems|Geographical Navigation Systems]] and [[Cultural Archives|Cultural Archives]] simultaneously. The principle: **when information is connected to [[Movement Through Space|Movement Through Space]], it becomes extraordinarily memorable.**

### [[30 Knowledge/Concepts/encoding-principles|Encoding Principles]]

1. **[[Sensory Richness|Sensory Richness]]** — add smell, taste, sound, texture
2. **[[Physical Action|Physical Action]]** — moving images stick better than static ones
3. **[[Emotion|Emotion]]** — [[Fear|Fear]], humor, surprise are powerful triggers
4. **[[Location|Location]]** — knowing WHERE something belongs helps retrieval
5. **[[Meaning|Meaning]]** — understanding why something matters helps it stick

## [[The Modern Problem|The Modern Problem]]

Schools teach what to think, not [[How to Remember|How to Remember]]. Students use laptops as [[External Brains|External Brains]] — but this makes real memory atrophy.
