## Each Summary Includes

- **What the book is about** — the core argument in 2–3 sentences
- **Core concepts** — 4–6 main ideas with specifics, not vague summaries
- **Key lessons** — 8–10 numbered takeaways you can act on
- **Practical applications** — how to use this right now
- **Controversy / criticism** — what people get wrong, what doesn't hold up
- **One-line takeaway** — the single most important thing to remember
- **Related books** — other summaries in the vault that connect
