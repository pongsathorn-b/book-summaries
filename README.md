## 📁 Format

Each book summary follows this structure:
1. **Overview** — what the book is about, why it matters
2. **Core Concepts** — 4–6 main ideas with specifics
3. **Key Lessons** — 8–10 numbered takeaways
4. **Practical Applications** — how to apply it
5. **Controversy/Criticism** — common objections, fair assessment
6. **One-Line Takeaway** — the distillation
7. **Related Books** — wikilinks to connected vault books, concepts, people

All files include YAML frontmatter (`tags`, `category`, `summary`).
